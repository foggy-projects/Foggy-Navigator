# BUG Work Item

## Background

SIM M4 Save Guard rehearsal reported that Actor-owned BusinessFunction invocation could not produce a clean `invoke_business_function` success path after importing and syncing:

- `functionId=world-sim.actor.tms-order-save-print.v1`
- `version=v1`

Owner smoke confirmed adapter, upstream route, and function visibility. The failure indicated inconsistent canonical handling across WorkerGateway, materialized schema, tool schema, and diagnostics.

## Reproduction

- LangBizWorker called `function_id=world-sim.actor.tms-order-save-print`, `version=v1` and received HTTP 400 `function not found`.
- CodexBizWorker used structured function calling, but WorkerGateway returned HTTP 400 and no `tms-order-save-print-result.json` was generated.
- `diagnostics session-dir` for Codex context returned the LangGraph path with `exists=false`.

## Expected vs Actual

Expected:

- Canonical invoke supports `function_id=world-sim.actor.tms-order-save-print.v1` with omitted or repeated `version=v1`.
- Compatibility lookup also accepts `function_id=world-sim.actor.tms-order-save-print`, `version=v1` when the stored function ID is versioned.
- Worker schemas and prompts present the canonical full function ID and do not encourage stripping `.v1`.
- Codex diagnostics can resolve the Business MCP debug log using `providerTaskId`.

Actual:

- Runtime invoke required `version` and exact `functionId`, so base ID plus version could miss imported versioned functions.
- Tool and materialized schema text allowed models to infer a stripped function ID.
- Diagnostics routed Codex context IDs through the LangGraph session resolver.

## Impact Scope

- BusinessFunction invocation through LangGraph Biz Worker and Codex Biz Worker.
- Materialized skill schema generated by the Business Agent module.
- Navigator upstream diagnostics for Codex Business MCP tool-call audit.

## Test Strategy

Unit-level regression coverage is required because the defect is concentrated in deterministic contract parsing, schema generation, and CLI diagnostics routing.

## Code Inventory

- `business-agent-module`: runtime function authorization, WorkerGateway invoke/schema, materialized skill schema.
- `addons/langgraph-biz-worker`: Java tool schemas and WorkerGateway client request shaping.
- `tools/langgraph-biz-worker`: Python LLM tool schemas and prompt guidance.
- `tools/codex-agent-worker`: Navigator Business MCP schema/request shaping.
- `navigator-open-sdk`: diagnostics CLI routing for Codex Business MCP logs.

## Fix Checklist

- [x] Make runtime `version` optional for WorkerGateway schema and invoke.
- [x] Resolve exact full function ID with current version when `version` is omitted.
- [x] Resolve base ID plus version to a stored versioned function ID for compatibility.
- [x] Return/audit canonical resolved function ID and version.
- [x] Update materialized schema and worker tool schemas to preserve `.v1`.
- [x] Add Codex diagnostics mode for Business MCP debug logs.
- [x] Add regression tests for exact ID, omitted version, repeated version, and base ID compatibility.
