# Navigator Provisioning Selftest Fixtures

This fixture set is generated by:

```powershell
.\tools\navigator-upstream\scripts\navigator-provisioning-selftest.ps1 -PrepareOnly
```

The prepare-only path does not call Navigator upstream admin APIs, does not require SIM or TMS credentials, and does not access real TMS. It generates local manifests under `temp/navigator-provisioning-selftest` and runs `worker-host verify` against the generated worker-host manifest.

Live mode is intentionally explicit. It requires gitignored profiles plus an LLM API key environment variable when a modelConfig must be created:

```powershell
$env:NAVI_SELFTEST_LLM_API_KEY = "<redacted>"
$env:NAVI_SELFTEST_WORKER_TOKEN = "<redacted>"
.\tools\navigator-upstream\scripts\navigator-provisioning-selftest.ps1
```

Use `system-profile.example.env` and `tenant-profile.example.env` only as placeholder references. Real profiles belong under `.navigator/` and must stay gitignored.

For a disposable local registration, pass `-GenerateEphemeralWorkerToken`. Do not use that switch when the worker already has a real configured token, because the registered token would not match the running worker.

Do not commit generated profiles, generated manifests with private endpoints, worker tokens, model API keys, runtime tokens, admin keys, control keys, claim tokens, cookies, real accounts, or passwords.

The selftest isolates Navigator platform provisioning from upstream business smoke. SIM and TMS dev keys should be delivered only after this local provisioning path passes.
